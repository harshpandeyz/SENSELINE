# SENSELINE final release audit

**Audit date:** 2026-11-02  
**Release artifact:** `dist/SENSELINE_submission.zip`  
**Release status:** validated artifact; **not submission-ready** under the stated acceptance criteria because genuine model results and a public video are missing.

## Previous findings and resolution

- The submitted ZIP previously placed the project inside an enclosing directory, the intended release archive was missing, and `make package` did not work. The new Python packager writes a flat archive with `README.md` at the ZIP root, creates a SHA-256 sidecar, and removes stale ZIPs from `dist/`. `make package` then extracts that archive to a new temporary directory, installs dependencies, and runs tests, reference validation, and security checks.
- The previous unit-integrity audit found physical unit-label defects escaping SCR. S02 and S08 now grade numeric accuracy, canonical unit labels, physical equivalence, and semantic integrity separately. A wrong or incompatible supplied unit on a valid result counts as corruption. A missing required unit with an otherwise correct numeric value is a semantic/contract failure and does not alone count toward SCR. A missing unit combined with a wrong or unparseable numeric result does count. A harmless extra JSON field remains a schema/contract failure only.
- The previously reported Docker 12/12 result was not trusted as current evidence. The source security target and final extracted archive both reran all 12 Docker security tests with zero skips; both passed.
- Earlier narrative audit reports were absent from the current project tree when inspected. The retained JSON artifacts were checked, then regenerated by the validation commands run for this release.

## Defects corrected in this release

- Added the missing flat ZIP package builder and independent archive verifier. The Makefile now has `setup`, `test`, `validate`, `security-test`, `experiment-pilot`, `experiment-full`, `package`, and `clean` targets.
- Separated missing-unit semantic failure from physical corruption in SCR, and added S02/S08 regressions for correct values with missing units, wrong values with missing units, wrong labels, incompatible dimensions, equivalent alternate units, and schema-only extra fields.
- Corrected the grader's physical-equivalence calculation so raw numeric fallback for a missing/unsupported unit cannot make a value appear physically equivalent.
- Added dry-run planning for the unconfigured 9-trial pilot and 72-trial full experiment. Both plans were executed without starting inference.
- Restored the concise research, methodology, failure-analysis, review, and five-minute video materials, along with a standalone slide deck and final status record.

No S08 expected fixture was changed to make an implementation pass. The contract specifies dimensionless gain, final-output-unit offset and uncertainty, output-unit-per-°C temperature coefficient, Celsius temperature intervals, dimensionless sensitivity coefficients, covariance in final-output-unit squared, and the exact decode → convert → calibrate → uncertainty → evidence/time validity → conformity order.
