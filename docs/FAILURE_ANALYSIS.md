# Failure analysis

Canonical evidence: 91 classified trials (`results/experiment_analysis.json`, generated by
`scripts/analyze_results.py` from raw trial records). Classification:

- **GENUINE** (14): candidate code was produced and Docker-graded under its registered budget. All model metrics
  use these trials only.
- **TOOL_USE** (58): the agent ran with reported usage but never produced an
  implementation (starter/empty/missing `solution.py`). Behavioral evidence, never
  scored as reasoning failures.
- **INFRA** (17): provider/launch failures with no usable candidate (including two
  opencode free-tier quota blocks). Excluded from all model numerators and denominators.
- **BUDGET_BREACH** (2): budget enforcer cut the agent off mid-work (S08 82740 tokens,
  S01 64271 tokens on 60k budgets); evidence preserved, excluded from primary metrics.

## Genuine reasoning and implementation failures

### 1. Controlled-vocabulary misses (contract violation, no corruption)

Full-run nemotron (7 trials, 216 cases: S01 96, S02 90, S03 30): accuracy 211/216
(0.977), schema 1.0, numerical 1.0, unit-label and physical-equivalence 1.0,
validity-state 1.0, SCR 0.0. The only 5 failures are reason-string mismatches on
correctly rejected invalid inputs:

- `S01-bad-scale` (3×): `{"valid": false, "reason": "invalid_scale"}` vs contract
  `"invalid_parameters"`.
- `S01-odd-nibble` (2×): `"frame_length"` vs contract `"invalid_frame"`.

Physics right, controlled vocabulary wrong. S02 and S03 are perfect (120/120).
Contract violations: 5/216. pass@3 = pass^3 = 1/2 (S02 perfect in all 3 trials;
S01 has no perfect trial under the strict all-correct definition).

### 2. Validity-propagation failures (silent corruption + unsafe acceptance, S08 pilot)

Two pilot S08 nemotron runs show the benchmark's core failure mode — computing
forward through every stage while failing to propagate stage-invalidity to the
final disposition:

Run A (attempt-4 history, `20261105T204856`, 32/45, UAR 2/23):

- `S08-unclear-traceability`: `traceability_not_documented` → model reported
  calibration evidence valid, overall `valid=true`, ACCEPT (expected INDETERMINATE).
- `S08-uncertainty-invalid`: invalid coverage factor → model ACCEPTed with a
  computed uncertainty instead of blocking.

Run B (pilot GENUINE, 0/45, UAR 3/23 — all three silent corruption):

- The same two traceability/uncertainty failures, plus
- `S08-truncated-frame`: a malformed frame (expected `decoded_measurement: null`,
  `error_reasons: ["decode:frame_length"]`) → the model invented
  `raw_count: 25` from the truncated frame and ACCEPTed.

Pooled genuine pilot nemotron (62 cases: S01 32, S05 30): accuracy 61/62 (0.984),
SCR 0. The S08 integration runs are evidence of the same failure mode at different
severities and are reported separately because neither is a clean budgeted completion:
run B (pilot GENUINE, 0/45, UAR 3/23) finished within budget and is the canonical S08
evidence; run A (BUDGET_BREACH, graded snapshot 32/45, UAR 2/23) was cut off by the 60k
token enforcer at 82740 tokens. Both show correct arithmetic with dropped certificate
evidence and malformed-frame handling — run A: 2 unsafe ACCEPTs; run B: 3, adding an
invented measurement from a truncated frame. The severity gap between runs with different
seeds is itself a finding: end-to-end validity handling is unstable.

### 3. What the strong model did right

- S01: signedness, endianness, width, scaling, sentinel rejection correct (only
  vocabulary misses).
- S02: 90/90 full-run affine conversions with exact unit labels.
- S03: 30/30 full-run calibrations with gain/offset order and temperature compensation.
- S05 (pilot): 30/30 Type A/B propagation with correlated contributors.

## Tool-use failures (behavioral, not reasoning)

`ollama/qwen3:8b` (full 18 TOOL_USE + history/pilot partials), `ollama/llama3.2:1b`
(24 + history), and the `ollama/qwen2.5-coder:7b` supplementary probe (1) almost
never invoked a file tool: successful-usage transcripts contain zero `tool_use`
events (qwen S05 pilot: 3 structured events total) versus 13 tool calls for a
genuine nemotron trial. They pasted code-like text into chat instead; the pasted
S01 text additionally used hallucinated field names (`hex`/`width`/numeric scale)
versus the exported contract (`frame_hex`/`width_bits`/string scale, `raw_count`
and string `value` outputs). The single exception across 59 local-model attempts:
one qwen S05 history trial that produced graded code scoring 1/30 (passing only
`S05-zero-factor`, 688 s, 12259 tokens). Under the locked-down edit-only,
shell-denied profile, small local models cannot operate the agent loop. This is a
reproducible agent-capability boundary — not a measurement-reasoning result — and
is reported as such.

## Infrastructure failures (excluded from metrics)

- 17 INFRA trials: fast `provider.no-route` / `Model unavailable` errors and one
  743 s provider hang from the opencode→Ollama router on local-model trials, plus two
  opencode free-quota blocks (beam, deepseek: `results/supplementary/`)
  (6 full-run, 4 pilot, 5 pilot-history, 2 supplementary; correlated with host memory
  pressure on the 16 GB machine), one setup-blocked trial from the pre-fix harness gate.
  All have no usable candidate and are excluded from every model numerator and
  denominator. (The OpenRouter quota halt stopped the run after a trial that still
  graded 30/30; that trial is counted GENUINE with its quota flag preserved.) Mitigated by single-resident-model scheduling and a
  bounded zero-cost retry (max 2, 30 s/90 s backoff; never for paid configs, budget
  stops, timeouts, or reported usage).
- The nemotron block halted with QUOTA_EXHAUSTED after 7 full trials: the OpenRouter
  free-model quota (50 requests/day at $0 pricing; account paid credits exhausted so
  paid calls fail closed with 402) is consumed at ~8–11 requests per agentic trial.
  One further trial recorded the quota flag while still grading 30/30 (counted
  GENUINE with the flag preserved). S04–S08 nemotron trials are missing pending the
  daily reset — absent, not zero.
- One full-run nemotron S01 trial was truncated by a 60000-token budget (an editing
  error; uniform budget is 120000) and is preserved as a budget finding, excluded
  from the canonical set. The gate that stopped the run on the breach worked as
  designed.

## Grader defects

None found. The S01 vocabulary misses are contract requirements the models failed,
not grader errors: reference and oracle agree on 266/266 cases, all 30 mutation
controls are rejected, and the S08 dimensional contract was frozen before any model
trial. The grader correctly gives zero credit to universal rejection (corruption
and decision metrics require the exact expected disposition) and counts
wrong-unit-marked-valid outputs as physical corruption while harmless extra fields
stay schema-contract violations.
