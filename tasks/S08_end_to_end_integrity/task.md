# S08 — End-to-End Measurement Integrity

## Problem

Preserve the meaning of one synthetic measurement through decoding, conversion, calibration, uncertainty, evidence checks, and conformity.

## Complete specification

The processing order is exact: (1) decode the register frame and scale into the sensor's declared `units.from_unit`; S01's `sensor.rounding_places` is applied here. Return `decoded_measurement` as `{raw_count, value, unit}` and set `unit` exactly to `units.from_unit`. (2) Convert that decoded value from `from_unit` to `to_unit` using S02's explicit affine rules; `physical_quantity.unit` must equal `to_unit`; no other unit conversion is inferred and conversion is not rounded again. (3) Apply `corrected = gain * physical_value + offset + temp_coefficient * (ambient_temperature_c - reference_temperature_c)` once. `gain` is dimensionless. `offset` is expressed in final `to_unit`; `temp_coefficient` is `to_unit` per degree Celsius. Both temperature inputs are in °C and their difference is a Celsius temperature interval; do not convert that interval to °F or K. `corrected_measurement.unit` must equal `to_unit`. The corrected result is rounded only by `calibration.rounding_places`. (4) The S05 uncertainty budget is supplied after calibration: every Type A observation and Type B half-width is already expressed in final `to_unit`. Sensitivity coefficients are dimensionless. Do not scale these uncertainty inputs by calibration gain or by the input-to-output unit conversion. `cov(i,j)=rho(i,j)*u_i*u_j` has unit `to_unit²`; combined standard and expanded uncertainty have unit `to_unit`. (5) Check S04 evidence using the corrected value, `to_unit`, serial, measurand and date. (6) Apply S06 to the corrected value, expanded uncertainty and specification limits; both limits are in `to_unit`, and the uncertainty interval uses the inclusive decision rule specified by S06. A worked Celsius-input/Fahrenheit-output example has decoded 25 °C → physical 77 °F; with gain 1, offset 0.9 °F, temperature coefficient 0.2 °F/°C and a +5 °C temperature interval, the corrected result is 78.9 °F. A post-calibration Type B half-width of 0.3 °F is not multiplied by gain. The required temporal object contains now_ms, timestamp_ms, max_age_ms, allowed_future_skew_ms, sequence, and optional last_sequence. Retain independent temporal, uncertainty and certificate checks when another independent stage fails. A missing corrected value makes certificate range applicability unavailable. Any failed stage leaves valid=false and conformity_decision=INDETERMINATE; no conformity interval is emitted unless all stages are valid. Error ordering is decode, temporal, units, calibration, uncertainty, certificate reason order, conformity, pipeline. Certificate uncertainty remains evidence only and is not combined into the supplied budget because its type/coverage/correlation are not given. Synthetic traceability implies no accreditation or legal compliance.
